# OpenCart 19.0 testing

## Source decision

Debian 13 Trixie does not package OpenCart. The appliance installs OpenCart
4.1.0.4 from the official GitHub release asset and verifies the SHA-256 digest
published by GitHub for that asset. OpenCart 4.1.0.4 is the current maintained
4.x release and supports PHP 8.1 or later. PHP 8.4, MariaDB and Apache come
from signed Trixie repositories.

OpenCart uses a supervised update path. Administrators back up the database,
storage and configuration before applying a reviewed official release and
following OpenCart's documented upgrade workflow.

## Acceptance command

```sh
/sandboxed-git/turnkey/tools/test-v19-appliance opencart \
    --source /home/agent/.local/worktrees/turnkey-apps/opencart/wish-opencart-v19-trixie
```

The command builds the Trixie root filesystem, boots its normal systemd and
firstboot path in Docker, and runs `tests/v19.sh`.

## README crosswalk

| README contract | Focused check | Required result |
| --- | --- | --- |
| OpenCart provides an online storefront and administration panel | Load the storefront and log in through the token-protected administrator form | Both primary web interfaces work over TLS |
| Firstboot sets the OpenCart administrator credentials | Log in with the preseeded password and inspect the stored hash | The dashboard loads and OpenCart's current password format is used |
| Administrators can manage store products | Create a product through the authenticated OpenCart controller | OpenCart returns a product ID and persists the product |
| Products are available through the storefront | Read the created product from MariaDB and request its public product page | The product exists in the database and appears in the storefront |
| Application state survives ordinary service restarts | Restart MariaDB and Apache, then repeat the product checks | The created product remains available |
| Adminer, Webmin and local mail support are available | Query MariaDB, inspect Webmin modules and HTTPS, and check Postfix's loopback listener | The database works, Webmin answers and local SMTP listens |
| Debian packages receive Trixie updates | Inspect installed packages and active APT suites | Required PHP and MariaDB packages are installed and no Bookworm source remains |
| OpenCart has a supervised upstream update path | Query the official release metadata and asset digest | The installed release and digest match the reviewed official archive |
| SSH, backup and other base services are inherited from Core | Reuse the passing Core 19 baseline | Core 19 acceptance remains the inherited evidence |

## Deferred issues

The focused acceptance creates and displays a real product without exercising
payments, shipping providers, third-party themes or extension upgrades. Those
flows depend on administrator-selected services and extensions rather than the
ordinary appliance installation, authentication, persistence and update paths
verified here.
